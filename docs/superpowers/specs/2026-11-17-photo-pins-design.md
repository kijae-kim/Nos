# 앨범 사진 핀 설계

2026-11-17 · 상태: 검토 반영, 승인 대기 · 앞: 프로필 묶음 · 다음: 1년 리캡(후순위)

## 왜

사용자: "그날 찍은 사진을 지도에서 둘러보고 싶어". 지금 기록 지도에는 장소 핀만 있다. 장소에서 200m 안에서 찍은 사진은 그 장소에 묶여 카드에 "사진 N장" 숫자로만 보이고, 근처에 장소가 없는 사진은 핀 지도에 전혀 나오지 않는다(색칠 지도에서 칠하는 데만 쓰인다). 또 사진은 최대 2560px 원본 하나뿐이라 지도·목록에서 작게 보여 줄 때도 큰 파일을 받는다.

## 목표

1. **작은 사진(썸네일)**: 사진마다 긴 변 320px JPEG 를 하나 더 만들어 R2 에 둔다. 지도 핀·사진 줄·앨범 목록에서 쓴다.
2. **장소 카드의 사진 줄**: 장소 핀을 누르면 카드에 그 장소 사진이 가로 줄로 (작은 사진). 누르면 사진 화면.
3. **사진 핀**: 근처에 장소가 없는(장소에 안 묶인) 위치 있는 사진은 작은 사진 동그라미 핀으로. 가까운 것끼리 숫자로 묶이고 확대하면 나뉜다. 누르면 그 자리 사진들이 같은 카드 줄로.
4. **날짜로 나누기**: 사진 줄은 찍은 날 순서, 날이 바뀌는 곳에 "11월 8일" 표시.
5. **`사진도 보기` 칩**: 핀 지도 아래, 가고 싶은 곳 칩 옆. 처음엔 켜짐, 기기에 기억(`nos.photoOverlay`).

## 하지 않는 것

- 날짜로 지도 거르기(특정 날만 보기), 사진 핀에서 바로 장소 만들기.
- 가고 싶은 곳 화면 지도의 사진 핀.
- 원본 사진 줄이기·바꾸기(원본은 그대로).

## 이러면 실패

- 작은 사진 용량이 무료 한도 계산에서 빠져 R2 가 과금된다.
- 사진을 지웠는데 작은 사진이 R2 에 남는다(저장 비용, 사생활).
- 작은 사진을 못 만들었다고 사진 올리기가 실패한다.
- 작은 사진에 촬영 위치(EXIF)가 남는다.
- 다른 커플 사진이 지도 데이터에 섞인다.

## 제약

- 모델이 바뀐다(`Photo.thumb`, `Photo.thumb_size`) → **Neon migrate 먼저**, 확인 숫자 **54**.
- 무료 한도: `quota.used_bytes` 에 `thumb_size` 합을 더한다. R2 목록 조회(LIST) 쓰지 않음.
- 사진은 비공개 R2, 1시간 서명 주소. 작은 사진도 같다.
- Vercel 요청 4.5MB: 작은 사진은 서버가 받은 파일로 만들므로 요청 크기와 무관.
- 문구 존댓말, 색 토큰, 375px·라이트/다크·배/여정.

## 방법 (고려한 것)

| 질문 | 고른 것 | 다른 길 |
|---|---|---|
| 핀 모양 | **작은 사진을 새로 만들어 동그라미 핀** (사용자) | 카메라 아이콘 핀 + 누를 때 원본: 단순하지만 둘러보는 느낌 약하고 느림·데이터 많음 |
| 작은 사진 크기 | **긴 변 320px, JPEG 품질 80 (30KB 안팎)** (내 판단) | 512px: 선명하지만 두 배 이상 |
| 장소 근처 사진 | **장소 핀에 묶어 카드 줄로** (사용자) | 모든 사진을 사진 핀으로: 장소 핀과 겹침 |
| 사진 핀 켜기 | **칩, 처음엔 켜짐** (내 판단, 사용자 확인) | 늘 보임 |

## 설계

### 저장 (마이그레이션 `couples.0015_photo_thumb` → Neon 54)

- `Photo.thumb = ImageField(upload_to=…, blank=True)` — 이름은 원본 이름에 `-thumb.jpg` (같은 커플 폴더). `Photo.thumb_size = PositiveIntegerField(default=0)`.
- 만들기: `make_thumb(file) -> ContentFile | None` (couples/thumbs.py). Pillow 로 열어 `exif_transpose`, 투명이면 흰 바탕, 긴 변 320px 로 줄여 JPEG 80 (EXIF 넘기지 않음). 열 수 없으면(HEIC 등) `None` — 올리기는 그대로 성공, 화면은 원본을 쓴다.
- 언제: `PhotoForm.save_for` 에서 새 이미지가 들어올 때(올리기·사진 바꾸기). 바꾸면 옛 작은 사진도 지운다.
- 지우기: 사진 지우기, 사진 바꾸기, 커플 마지막 사람이 나갈 때(`leave`) 원본과 함께.
- 용량 한도: `used_bytes` = 사진 `size` + `thumb_size` + 취향 `image_size`. 올리기 전 검사는 지금처럼 원본 크기로(작은 사진은 원본의 약 2%라 한도 여유 안에서 감당; 내 판단).
- 이미 올린 사진 채우기: `python manage.py make_photo_thumbs [--dry-run] [--limit N]` — `thumb` 없는 사진만, 원본을 R2 에서 한 번 GET 해 만든다. 운영은 `ENV_FILE=.env.neon`. LIST 없음. 한도 검사는 하지 않고(작은 사진은 원본의 약 2%), 끝나면 커플별 사용량과 한도를 출력해 넘은 커플이 있으면 알린다(내 판단).
- `Photo.thumb_url` property: 작은 사진이 있으면 그 주소, 없으면 원본 주소.

### 지도 데이터

- `place_map_data` 그대로 + 각 장소의 `photos` 수(지금처럼).
- 장소 카드 사진 줄: `GET /tastes/places/<pk>/photos/data/` `place_photo_strip` → `{"photos": [{"id","thumb","url","date"}]}` (찍은 날 순, 날짜 없으면 올린 날, 최대 60장). 내 커플 장소만(아니면 404).
- 사진 핀: `GET /tastes/photos/data/` `photo_map_data` → `{"photos": [{"id","lat","lng","thumb","url","date"}]}` — 내 커플의 위치 있는 사진 중 **장소에 안 묶였거나, 묶인 장소에 위치가 없는 것**(지도에 보일 곳이 없는 사진이 없게). 최근 찍은 순 **500장까지**(내 판단: 두 사람 규모에 충분, 데이터·핀 수 제한). `date` = `taken_on` 또는 올린 날(ISO). 작은 사진이 없으면 `thumb` 는 `null`.

### 지도 화면 (map.js 기록 지도, 핀 지도에서만)

- `사진도 보기` 칩(`[data-photo-overlay]`), 켜면 `photo_map_data` 를 받아 사진 핀을 장소 핀과 **같은 묶음**에 넣는다(카카오: CustomOverlay, Leaflet: divIcon). 국내/해외는 좌표로(`scopeOf`).
- 사진 핀 모양: 34px 동그라미 안에 작은 사진(`background-image`), 흰 테두리. 작은 사진이 없는 사진(HEIC 등)은 **카메라 아이콘 동그라미** — 핀에 원본을 받지 않는다(내 판단). 묶음 숫자는 지금 모양.
- 사진 핀을 누르면: 그 사진과 **좌표 기준 50m 안** 사진들을 카드 줄로 — 브라우저가 이미 받은 사진 핀 목록에서 계산한다(새 주소 없음, 내 판단). 장소 핀을 누르면: 장소 카드 + 사진 줄(위 주소로 받아 옴).
- 카드 사진 줄: 가로 스크롤, 64px 정사각형 작은 사진(없으면 원본, `loading=lazy`), 날이 바뀌는 곳에 날짜 표시("11월 8일"). 누르면 사진 화면(`photo_detail`). 장소 사진이 60장보다 많으면 줄 끝에 "모두 보기 ›"(장소 사진 화면 `place_photos`) — 카드의 "사진 N장" 과 어긋나지 않게(내 판단).

### 앨범 목록

- `album.html`·`album_detail.html`·`place_photos.html`·`taste_detail.html` 의 격자·표지 사진은 `thumb_url`. 사진 화면(`photo_detail`)과 고치기 미리 보기는 원본.

## 빌더에게 맡기는 것

- 작은 사진 파일 이름 규칙의 세부, 사진 핀·줄의 세부 모양.
- 50m 묶기 계산 위치(브라우저에서 받은 사진 목록으로 계산해도 됨).

## 내가 정한 것 (사용자 확인 필요)

- 작은 사진은 긴 변 320px. 앨범 목록 격자도 작은 사진으로 바꿔 가볍게 한다.
- 작은 사진을 못 만들면(HEIC 등) 올리기는 성공하고 원본을 그대로 쓴다.
- `사진도 보기` 는 처음엔 켜져 있다.
- 사진 핀을 누르면 50m 안 사진을 함께 보여 준다.
