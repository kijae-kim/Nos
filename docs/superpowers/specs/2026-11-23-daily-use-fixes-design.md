# 써 보며 나온 것 고치기 (2026-11-23) 설계

2026-11-23 · 상태: 승인 대기 · 앞: 메모 · 다음: 1년 리캡(후순위)

## 왜

사용자가 하루 동안 앱을 써 보고 불편한 점 12가지를 정리했다. 공통 줄기는 **덜 누르고 바로 쓰기**(+ 버튼이 그 화면의 추가, 글로 일정 쓰기, 메모 체크 단축)와 **화면을 가볍게**(큰 버튼·이름표·긴 목록 줄이기).

## 사용자가 정한 것

- 로딩(시작) 화면에서 위·아래 바 색을 맞춘다.
- 메모: `/todo` 나 `-` + 띄어쓰기로 체크 항목. 메모를 남기면 상대에게 알림.
- 캘린더: 오늘 날짜는 검게 채우지 말고 표시만.
- 추억: 나·상대 구분 버튼이 너무 크다 → "추억" 제목과 같은 줄 오른쪽 끝 작은 버튼.
- 기록 색칠 지도: 가고 싶은 곳이 이름으로 나오는데, 이름 대신 색으로.
- + 버튼: 홈에서는 메뉴, 캘린더는 일정 추가, 추억은 추억 저장, 앨범은 사진 추가.
- 글로 일정: "12월 25일 찜질방가기" 를 쓰면 일정으로. **규칙으로 먼저**(무료), 모르면 등록 화면으로. LLM 은 나중.
- 색: 종류를 늘리고, 이름 없이 팔레트(색 동그라미)만. 이름이 칸을 많이 차지한다.
- 홈: 기념일 아래 목록 4개(메모·일정·추억·사진)를 **'오늘' 한 칸**으로.

## 하지 않는 것

- LLM 연결(나중에 같은 자리에 붙일 수 있게만).
- 메모 실시간 함께 쓰기, 알림 묶음 화면(알림 목록).
- 색 이름 직접 짓기, 색 고르는 원형 색상환.

## 이러면 실패

- 알림이 글자마다·저장마다 와서 귀찮다.
- 글로 일정이 날짜를 잘못 알아듣고 **말없이** 엉뚱한 날에 넣는다 (넣기 전에 늘 팝업으로 확인).
- 홈 + 메뉴를 다른 화면에서 못 쓰게 돼 길을 잃는다.
- 색을 늘렸는데 다크 모드에서 글이 안 읽힌다.
- 메모에서 `-` 로 시작하는 보통 글(예: "-5도")이 체크로 바뀐다.

## 제약

- 문구 존댓말, 색 토큰, 375px·라이트/다크·배/여정.
- 모델 바꾸면 Neon migrate (지금 55 → 늘어난 숫자는 계획에서 정함).
- 무료 한도: 알림은 기존 웹 푸시(`notifications` 앱)만, 외부 유료 API 없음.

## 방법 (고려한 것)

| 질문 | 고른 것 | 다른 길 |
|---|---|---|
| 글로 일정 | **규칙 해석(서버 파이썬), 결과로 날짜 팝업을 채워 확인 후 추가** (사용자) | LLM(Claude Haiku): 아무 말투나, 키·사용료 |
| 홈 아래 | **'오늘' 카드 하나** (사용자) | 다 지우기 / 숫자 타일 4개 |
| 메모 알림 간격 | **같은 메모는 30분에 한 번, 상대가 알림 켰을 때만** (내 판단) | 저장마다: 너무 잦음 / 하루 요약: 늦음 |
| + 버튼 | **짧게 누르면 그 화면의 추가, 꾹 누르면 전체 메뉴** (내 판단) | 화면마다 메뉴 내용만 바꾸기: 한 번 더 눌러야 함 |

## 설계

### 1. 시작 화면 바 색 (`base.html`, `theme.js`)
- 시작 화면이 보이는 동안 `theme-color` 를 시작 화면 바탕(`--hero-bg` 와 같은 색)으로, 끝나면 앱 색으로 되돌린다. 아이폰 홈 화면 앱 아래 바(홈 표시줄 영역)도 같은 색이 되게 시작 화면이 안전 영역까지 덮는다.

### 2. 캘린더 오늘 (`app.css`)
- 캘린더 `.day.sel` 채움을 없앤다(팝업이 생긴 뒤로 '고른 날' 은 의미 없음). 오늘은 테두리 고리 + 글자 색만. 넓은 화면 `.cell.today` 도 같은 방식. 기념일 화면 작은 달력도 맞춘다.

### 3. 추억 누가 남겼는지 (`taste.html`)
- 세 칸 버튼(`segment three`)을 지우고, 머리 줄 "추억" 오른쪽 끝 작은 알약 버튼 하나: 누르면 `모두 → 나 → 상대` 차례로(주소 `?who=` 그대로). 기록 탭에서는 숨김.

### 4. 색칠 지도 (`coloring-map.js`)
- 지도 위 지역 이름 글자를 없앤다(전국·서울·구 단계 모두). 다녀온 곳은 진한 색, 가고 싶은 곳만 있는 지역은 같은 색 옅게 + 빗금. 이름은 지역을 누르면 나오는 아래 판에서. 지도 아래 작은 범례("다녀온 곳 · 가고 싶은 곳").

### 5. 메모 체크 단축 (`memo-editor.js`)
- 글 줄 맨 앞에서 `- `(빼기+띄어쓰기) 또는 `/todo `(띄어쓰기까지)를 치면 그 글자를 지우고 체크 줄로. 이미 체크 줄이면 그대로. 줄 가운데에서는 바뀌지 않음. `-5도` 처럼 띄어쓰기가 없으면 그대로. 한글 입력 중(조합)에는 판단하지 않고 끝난 뒤.

### 6. 메모 알림 (`memos`, `notifications`)
- 메모가 저장될 때 쓴 사람이 아닌 상대에게 웹 푸시 "○○님이 메모를 고쳤어요: 제목", 누르면 그 메모. 같은 메모는 **30분에 한 번**(메모별 마지막 알림 시각 기록). 상대가 알림 설정에서 '메모' 를 켰을 때만(기본 켬). 보내기 실패가 저장을 막지 않음.

### 7. + 버튼 (`layout_app.html`, `app.js`)
- 짧게 누르기: 홈·메모·기념일·우리 → 지금처럼 메뉴. 캘린더 → 오늘 날짜 팝업. 추억 순간 탭 → 순간 남기기, 기록 탭 → 기록 남기기. 앨범 → 사진 올리기.
- 꾹 누르기(0.5초): 어느 화면이든 메뉴. 버튼 모양에 작은 차이(메뉴가 아닌 화면에서는 아이콘 아래 화면 이름 대신 그대로 +). 화면 읽기 프로그램용 이름도 바뀜("일정 추가" 등).

### 8. 글로 일정 (`couples/quickparse.py`, 캘린더)
- 캘린더 맨 위 한 줄 입력칸 "무엇을 언제 할까요? 예: 12월 25일 찜질방 가기". 보내면 서버가 해석:
  - 날짜: `12월 25일`, `12/25`, `25일`, `오늘·내일·모레`, `이번/다음 주 금요일`, `금요일`(다가오는), `12월 25일~27일`·`25~27일`(끝나는 날).
  - 시간: `저녁 7시`, `오후 3시 반`, `19:30`, `3시~5시`.
  - 나머지 글이 일정 이름(@ # 그대로).
- 날짜를 찾으면 그 날짜 팝업을 열고 이름·시간을 채워 둔다(사용자가 '추가' 를 눌러야 저장). 못 찾으면 `event_create?text=` 로.
- 지난 날짜(올해 이미 지난 12월 25일이 아닌 '3월 1일' 등)는 내년으로.

### 9. 색 팔레트 (`COLOR_CHOICES`, `app.css`, `_choices.html`)
- 6색 → 12색. 새 색 이름은 토큰 이름(코드용)만, 화면에는 이름 없이 동그라미만(누를 때 고른 표시, 화면 읽기용 이름은 남김). 테마×모드 4조합 모두 토큰, 일정 막대 위 흰 글이 읽히게(대비 4.5 이상 목표).

### 10. 홈 '오늘' 카드 (`home.html`, `couples/views.py`)
- 기념일 카드·다가오는 기념일은 그대로. 그 아래 메모·일정·추억·사진 네 목록을 지우고 '오늘' 카드 하나:
  - 오늘·내일 일정(없으면 "오늘은 일정이 없어요" + 가까운 다음 일정 하나).
  - 최근 3일 안에 **상대가** 새로 남기거나 고친 것 최대 3줄(메모·순간·기록·사진), 누르면 그것.
  - 아무것도 없으면 짧은 안내.

## 검토에서 정한 것 (내 판단)

- 홈 '오늘' 카드: 순간·기록·사진은 **새로 남긴 것만**(작성자 `author`·`uploaded_by` 기준), 메모만 고친 것도(`updated_by`). 순간·사진에 '고친 사람' 칸을 더하지 않는다.
- 메모 알림 설정: `User.notify_memo`(기본 켬). 웹 푸시를 켠 사람(구독이 있는 사람)에게만 실제로 간다. 30분 간격은 `Memo.notified_at` 에 기록.
- + 버튼(캘린더): 보고 있는 달에 오늘이 있으면 오늘, 아니면 그 달 1일 팝업. 꾹 누르면 메뉴라는 것은 메뉴가 아닌 화면에서 처음 한 번 작은 안내("꾹 누르면 메뉴가 열려요")로 알린다(기기 저장소).
- 글로 일정: 입력칸은 폰·넓은 화면 캘린더 모두. 끝나는 날은 이미 있는 `Event.end_date`. 해석 실패면 글 전체를 `event_create?text=` 로.
- 색: 기존 6개 이름(sky 등) 그대로 두고 6개 더함, 이름 10자 이하. 선택지만 바뀌어도 마이그레이션이 생긴다.
- 마이그레이션: accounts(notify_memo), memos(notified_at), couples(색 선택지) 각 1개 → Neon 확인 숫자 **58**.
- 색칠 지도의 가고 싶은 곳: 지금 지역 판정은 다녀온 곳·사진만 하므로, 가고 싶은 곳도 같은 방식(좌표 → 지역)으로 판정하는 부분을 더한다.

## 빌더에게 맡기는 것

- 각 화면 세부 모양, 새 색 6개 고르기, 범례 모양, 해석 규칙의 세부(위 목록은 꼭 알아들을 것).

## 내가 정한 것 (사용자 확인 필요)

- 메모 알림은 같은 메모 30분에 한 번, 기본 켬.
- + 버튼은 꾹 누르면 어느 화면이든 메뉴.
- 글로 일정은 바로 저장하지 않고 팝업에서 확인 후 '추가'.
- 홈 '오늘' 카드는 상대가 바꾼 것만 보여 준다(내가 한 건 이미 앎).
- 추억 누가 버튼은 누를 때마다 차례로 바뀌는 한 개.
