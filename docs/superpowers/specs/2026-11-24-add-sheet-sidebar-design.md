# + 는 추가 팝업, 메뉴는 사이드바 설계

2026-11-24 · 상태: 승인 대기 · 앞: 써 보며 나온 것 고치기

## 왜

어제 + 를 화면마다 '그 화면의 추가'로 바꿨지만 추억·앨범은 다른 화면으로 넘어가고, 메뉴는 꾹 눌러야 나와 찾기 어렵다. 사용자는 **+ 는 어디서나 '추가' 팝업**, **어디로 갈지(무엇을 만들지)는 왼쪽 위 NÓS 사이드바**로 나누길 원한다.

## 사용자가 정한 것

- + 를 누르면 화면마다 추가 팝업: 캘린더(날짜 팝업, 지금 그대로), 추억(순간·기록 남기기), 앨범(사진 올리기). **팝업 안은 지금 등록 화면 전체**.
- 홈의 + 는 **오늘 일정 추가** 팝업.
- 팝업이 올라오면 + 가 **닫기(×)** 버튼으로 바뀐다.
- 추억 화면의 '순간 남기기' 버튼은 지운다(+ 로 추가).
- 아래 바(홈·캘린더·+·추억·앨범) 색을 페이지 바탕과 구분되게.
- 왼쪽 위 NÓS 를 누르면 사이드바: **새로 만들기 6개(일정·순간·기록·메모·사진·기념일) + 화면 바로가기(메모·기념일·가고 싶은 곳·우리·알림 설정)**.

## 하지 않는 것

- 넓은 화면(900px 이상): 지금 옆 메뉴 그대로, + 와 사이드바는 폰 화면 것.
- 등록 화면 자체(칸·순서) 바꾸기.

## 이러면 실패

- 팝업 안에서 링크 미리 보기·장소 찾기·사진 줄이기·드라이브 가져오기 같은 지금 기능이 안 된다.
- 저장했는데 팝업이 안 닫히거나 목록에 안 보인다.
- 팝업이 열린 채 + 가 다른 동작을 한다 / 닫기를 못 찾는다.
- 스크립트가 없으면 아무것도 못 한다 (→ + 는 그대로 등록 화면 링크로 동작해야 한다).

## 방법 (고려한 것)

| 질문 | 고른 것 | 다른 길 |
|---|---|---|
| 팝업 안 등록 화면 | **팝업 안에 등록 화면을 그대로 띄우기(iframe, `?sheet=1` 이면 위·아래 바 없는 모양)**. 지금 스크립트(미리 보기·장소·사진 줄이기·드라이브)가 손대지 않고 그대로 돈다 (내 판단) | 화면 조각을 받아 끼우기: 지금 날짜 팝업처럼 가볍지만, 등록 화면 스크립트를 모두 '다시 붙이기' 가능하게 고쳐야 해 위험이 크다 |
| 팝업과 + 의 겹침 | **팝업을 아래 바 위에 띄우고(바는 보임) + 가 × 로** (내 판단) | 화면 전체를 덮는 창: + 가 가려져 × 로 못 쓴다 |
| 저장 뒤 | **팝업 안 화면이 등록 화면을 벗어나면(저장 뒤 상세 화면으로) 팝업을 닫고 그 상세 화면으로 이동** (내 판단) | 목록 새로 고침: 방금 만든 것을 바로 못 봄 |

## 설계

- **추가 팝업 틀 하나**(`layout_app.html`): 아래에서 올라오는 판, 아래 바 바로 위까지, 뒤는 어둡게. 날짜 팝업(캘린더·홈)도 같은 자리·모양.
- **+ 동작**: 화면이 준 추가 주소로 팝업 열기. 캘린더·홈은 날짜 팝업(`day_popup`), 추억·앨범은 등록 화면을 `?sheet=1` 로 팝업 안에. 팝업이 열려 있으면 + 는 × (누르면 닫기, 화면 읽기 이름 "닫기"). 꾹 누르기 메뉴와 반원 메뉴는 없앤다.
- **`?sheet=1` 화면**: 위 머리(뒤로 버튼)는 × 닫기로, 아래 바·사이드바 없음. 저장해서 다른 주소로 가면 부모가 팝업을 닫고 그 주소로 이동. 앨범 안에서 + 는 그 앨범으로 올리기(`?album=`).
- **사이드바**: NÓS(왼쪽 위 로고) 를 누르면 왼쪽에서 나오는 판. 위 '새로 만들기' 6개(누르면 판을 닫고 그 추가 팝업 또는 화면), 아래 '바로가기'. 바깥 누르기·Esc·뒤로 닫기. 스크립트 없으면 로고는 지금처럼 홈 링크.
- **아래 바 색**: 바 바탕을 페이지 바탕과 다른 토큰(라이트는 진한 표면, 다크는 한 단계 밝은 표면) + 위쪽 경계선. 4조합 확인.
- **추억 '순간 남기기' 버튼 지움** (기록 탭에는 원래 없음).

## 빌더에게 맡기는 것

- 판 높이·움직임, 사이드바 폭·모양, 바 색 값, iframe 높이 맞추기.

## 내가 정한 것 (사용자 확인 필요)

- 팝업 안 등록 화면은 iframe 으로 (지금 기능 그대로 쓰려고).
- 팝업은 아래 바 위까지만 덮고, 아래 바는 보인다.
- 저장하면 팝업을 닫고 새로 만든 것의 상세 화면으로.
- 꾹 누르기 메뉴·반원 메뉴는 없앤다 (사이드바로 옮김).
- 넓은 화면은 지금 그대로.
