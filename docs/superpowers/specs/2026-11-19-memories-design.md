# 추억 (순간 · 기록) 설계

2026-11-19 · 상태: 검토 반영, 승인 대기 · 앞선 설계: `2026-11-16-photo-map-design.md` (앨범 지도 → 이 설계로 옮겨 감)

## 왜

함께 간 곳을 지도 위에 쌓아 두고, 그곳에서 찍은 사진과 이어서 다시 보고 싶다. 지도는 앨범의 한 칸이 아니라 "다녀온 곳을 기록하는 곳"이어야 한다. 영화·음악·영상·책 같은 취향 공유는 "순간"으로 묶는다.

## 목표

- 하단 탭 **취향 → 추억**. 들어가면 `순간 · 기록` 전환.
- **순간**: 영화·음악·영상·책 글. 분류 버튼 줄을 없애고, 글을 쓸 때 **태그로 하나** 고른다. 목록은 태그 칩으로 걸러 본다(`전체 · 영화 · 음악 · 영상 · 책`). "둘 다/나/상대" 거르기, 좋아요·댓글, 링크 미리보기는 그대로.
- **기록**: 지도 + 장소 목록. 장소 = 분류가 "장소"인 취향 글에 위치를 더한 것.
  - 지도: 국내 카카오맵 / 해외 Leaflet, `국내 · 해외` 전환 (앨범 지도에서 만든 것 재사용).
  - 핀을 누르면 그 장소 카드, 누르면 장소 글 화면.
  - **+** 로 장소 기록: 위치는 **이름 검색(기본)**, **지도에서 직접 찍기**, **사진에서 가져오기** 셋 다.
- **사진 ↔ 장소 연결: 자동 + 직접 고치기.**
  - 자동: 촬영 위치가 있는 사진은 **200m 안의 가장 가까운 장소**에 붙는다.
  - 직접: 사진 화면(고치기)에서 장소를 바꾸거나 떼고, 장소 화면에서 사진을 골라 붙이거나 뗀다. 직접 정한 것은 자동이 다시 바꾸지 않는다.
- 장소 글 화면: 주소, 작은 지도, "이곳에서 찍은 사진" 모음(+ 직접 고르기).
- 앨범의 **지도 칸은 없앤다**. 사진 화면의 "지도에서 보기"는 연결된 장소가 있으면 그 장소 글로, 없으면 기록 지도의 그 위치로.

## 하지 않는 것

- 장소 리뷰·별점, 경로·이동선, 지도 공유, 구글 장소 검색.
- 순간 글에 위치 넣기. 일정(캘린더) 장소를 지도에 올리기.
- 순간의 태그를 사용자가 새로 만들기 (영화·음악·영상·책 고정).

## 이러면 실패 (기술적으로 동작해도)

- 과금이 생긴다 (카카오 장소 검색·지도, OpenStreetMap 검색 모두 무료 한도 안. 구글·네이버는 쓰지 않는다).
- 위치·사진이 커플 밖으로 새어 나간다.
- 직접 고친 사진-장소 연결이 자동 연결에 덮어써진다.
- 지금 있는 취향 글(좋아요·댓글 포함)이 사라지거나 엉뚱한 칸으로 간다.
- 카카오맵이 실렸는데 지도가 비어 보인다 (지금 운영에서 생긴 문제).

## 제약

- 모델이 바뀐다 → Neon migrate 를 배포보다 먼저 (집 맥).
- 카카오 키: 지도는 JavaScript 키(`KAKAO_JS_KEY`, 도메인 등록 완료), 장소 검색은 **REST API 키(`KAKAO_CLIENT_ID`, 로그인에 쓰는 것과 같은 앱 키)** 로 서버가 부른다. 키를 화면에 내보내지 않는다.
- OpenStreetMap 검색(Nominatim)은 사용 정책상 초당 1회, 식별 가능한 User-Agent(앱 이름만, 개인 정보 없이), 결과 출처 표기.
- 사진 주소는 1시간 서명 주소. R2 LIST 금지.
- 지금 운영에서 카카오맵이 안 그려지는 원인은 실제 키로 재현해야 찾는다 → 맥 `.env` 에 `KAKAO_JS_KEY` 를 사용자가 넣는다 (`http://localhost:8000` 도메인 등록 필요).

## 방법 (고려한 것)

| 질문 | 고른 것 | 다른 길 |
|---|---|---|
| 장소를 무엇으로 | **취향 글(분류 "장소")에 위치를 더함** — 좋아요·댓글·링크 미리보기·사진을 그대로 씀 | 따로 장소 모델: 깔끔하지만 같은 기능을 두 벌 만들고 글이 둘로 나뉨 |
| 사진 연결 | **자동(200m) + 직접 고치기** | 자동만: 위치 없는 사진·겹치는 장소를 못 고침 / 직접만: 손이 많이 감 |
| 위치 정하기 | **검색 기본 + 지도에서 찍기 + 사진에서** | 하나만: 검색에 없는 곳·사진만 있는 곳을 못 담음 |
| 지도 위치 | **추억 › 기록 한 곳** (앨범 지도 칸 없앰) | 둘 다 둠: 지도 두 벌, 헷갈림 |

모두 사용자가 고른 것이다.

## 설계

### 저장 (마이그레이션 → Neon)

- `Taste`: `latitude`, `longitude` (FloatField null), `address` (CharField 200, blank), `place_url` (URLField blank, 카카오 장소 페이지 등). 위치 검사는 `couples/geo.clean_coords` 를 쓴다.
- `Photo`: `place` (FK → Taste, null, `SET_NULL`, `related_name="place_photos"`, 분류 "장소" 글만), `place_manual` (Boolean, 기본 False: True 면 자동 연결이 건드리지 않음).
- 순간 글(음악·영화·영상·책)과 장소 글은 같은 `Taste` 표에 있고 `category` 로 나뉜다. 지금 있는 글은 그대로 두고, "장소" 글은 기록 쪽에 보인다 (위치가 없으면 목록에만, "위치 넣기" 표시).

### 자동 연결 규칙 (`couples/places.py`)

- `nearest_place(couple, lat, lng) -> Taste | None`: 같은 커플의 위치 있는 장소 글 중 200m 안에서 가장 가까운 것 (거리: 하버사인). 거리가 같으면 **먼저 만든 글(작은 pk)**.
- 연결은 코드로 지킨다: 사진과 장소 글은 같은 커플, 장소 글은 `category="장소"` 만. 장소 글의 분류는 바꿀 수 없다 (장소 폼에 분류 칸이 없고, 순간 폼에는 "장소" 가 없다).
- 재계산은 커플의 위치 있는 사진·장소를 한 번에 읽어 파이썬에서 계산하고 바뀐 것만 `bulk_update` 한다 (두 사람 규모: 사진 수천 장도 1초 안).
- 사진이 위치를 얻을 때(올리기, `fill_photo_locations`) `place_manual` 이 아니면 `place = nearest_place(...)`.
- 장소 글이 위치를 얻거나 바뀔 때: 같은 커플의 `place_manual=False` 이고 위치 있는 사진을 다시 계산한다 (가장 가까운 장소로).
- 장소 글을 지우면 연결된 사진은 `place=None` (자동인 것은 다시 계산해 다른 장소가 200m 안이면 거기로).
- 사용자가 사진의 장소를 바꾸거나 떼면 `place_manual=True`.
- 기존 "장소" 글은 위치가 없으니 자동 연결 대상이 아니다. "위치 넣기" 로 위치를 얻는 순간 재계산된다. "자동으로 되돌리기" 를 고르면 `place_manual=False` 후 다시 계산.

### 장소 검색 (`couples/placesearch.py`, 서버)

- `GET /memories/places/search/?q=` (로그인): 결과 `[{name, address, lat, lng, url, source}]` 최대 10개.
  1. 카카오 로컬 키워드 검색 (`https://dapi.kakao.com/v2/local/search/keyword.json`, `Authorization: KakaoAK <KAKAO_CLIENT_ID>`).
  2. 카카오 결과가 3개 미만이면 Nominatim (`https://nominatim.openstreetmap.org/search?format=jsonv2&accept-language=ko&limit=5`) 결과를 뒤에 붙인다 (해외).
- 요청 시간 제한 5초, 실패하면 빈 목록 + "검색이 잠시 안 돼요. 지도에서 직접 찍어 볼까요?".
- Nominatim 은 서버에서 사용자마다 1초에 한 번만 (캐시: 같은 검색어 결과 하루 보관, Django cache).
- 화면은 입력 중에 부르지 않고 **검색 버튼(엔터)** 을 눌렀을 때만 부른다.

### 화면

- **하단 탭·문구**: 취향 → 추억 (아이콘은 그대로), 빠른 추가 메뉴의 "취향" → "순간" 과 "기록" 둘로 (아이콘 note / pin). 홈의 "바다가 공유한 음악" 같은 줄은 그대로 두되 탭 이름만 바뀐다. 테마별 문구(`t-boat`/`t-journey`) 중 "취향" 은 "추억" 으로.
- **추억 화면** (`/tastes/` 주소는 그대로, `?tab=moment|record`, 기본 순간):
  - 순간: 태그 칩 `전체 · 영화 · 음악 · 영상 · 책`, "둘 다/나/상대", 카드 목록, "순간 남기기" 버튼. **"전체" 에도 장소 글은 나오지 않는다** (기록에만). 홈의 최근 글 줄은 지금처럼 순간·장소 모두 보인다.
  - 기록: `국내 · 해외` 지도(위치 있는 장소 핀, 사진 수에 따라 지역 색칠은 하지 않고 핀만), 아래에 장소 목록(최근 순, 장소마다 사진 수), "장소 기록하기" 버튼. 위치 없는 장소 글은 목록에 "위치 넣기" 표시.
- **순간 쓰기**: 분류 칸을 태그 칩 하나 고르기(영화·음악·영상·책)로, **꼭 골라야 한다** (안 고르면 "태그를 하나 골라 주세요"). "장소" 는 여기서 고를 수 없다. 장소 글을 고치면 장소 폼으로 간다.
- **장소 기록하기 / 고치기**: 이름, 한마디, 사진(선택), 링크(선택) + 위치 칸:
  - 검색 칸(기본) → 결과 목록에서 고르면 이름(비어 있으면)·주소·위치가 들어가고 작은 지도에 핀.
  - "지도에서 찍기" → 지도 가운데 고정 핀, 움직여서 "여기로".
  - "사진에서" → 위치 있는 앨범 사진 격자(최근 60장)에서 하나 고르면 그 위치. 그 사진은 이 장소에 직접 연결(`place_manual=True`).
- **장소 글 화면**: 지금 취향 자세히 + 주소, 작은 지도(Leaflet, 국내도 카카오맵), "이곳에서 찍은 사진" 격자(자동/직접 표시 없이), "사진 고르기"(위치 상관없이 커플 사진에서 골라 붙이기·떼기).
- **사진 고치기**: "장소" 선택 칸(장소 글 목록 + "없음" + "자동으로"). 사진 화면에 연결된 장소 이름 표시.
- **앨범**: 지도 칸과 `map.js` 의 앨범 쪽 연결을 없앤다. `album_map_data` 주소는 없앤다(404). 예전 주소 `/albums/?view=map&focus=…` 는 기록 지도(`/tastes/?tab=record&focus=…`)로 넘긴다.

### 지도 코드

- `static/js/map.js` 를 기록 화면용으로 바꾼다: 데이터는 장소 목록(`/memories/places/data/`: `[{id, name, lat, lng, photos, url}]`), 핀을 누르면 지도 아래 장소 카드. 경계 파일은 국내/해외 판정에만 쓰고 색칠은 하지 않는다.
- **운영의 카카오맵 빈 화면 원인을 실제 키로 재현해 고친다.** 사용자가 맥 `.env` 에 키를 넣으면 바로 하고, 그 전까지 다른 작업을 먼저 한다 (막지 않는다). 기록 지도는 Leaflet 으로 먼저 완성한다. 카카오맵이 실린 뒤 그리기에서 실패하면 Leaflet 으로 바꿔 그린다는 원칙은 유지.

### 무료 한도

- 카카오 로컬 검색·지도 표시: 무료 한도(일 수십만 회)에 비해 두 사람 사용량은 매우 작다. Nominatim: 초당 1회 제한을 서버가 지킨다. 추가 저장 공간 없음.

## 빌더에게 맡기는 것

- 장소 검색 결과 화면 모양, 지도에서 찍기 화면의 세부, 사진 고르기 격자 페이지 나누기.
- 하버사인 계산 위치(파이썬), 자동 재계산을 저장 시점(서비스 함수)에서 할지 시그널로 할지 — **서비스 함수 권장** (명시적).
- 기존 앨범 지도 테스트를 기록 지도 테스트로 옮기기.

## 내가 정한 것 (사용자 확인 필요)

- 같은 거리면 먼저 만든 장소에 붙는다. 장소 글의 분류는 바꿀 수 없다.
- 순간의 "전체" 에 장소 글은 안 나온다. 순간 태그는 꼭 골라야 한다.
- 예전 앨범 지도 주소는 기록 지도로 넘긴다.

- 자동 연결 거리 **200m**, 가장 가까운 한 곳.
- 기록 지도는 지역 색칠 없이 **핀만** (장소 단위라 색칠보다 핀이 맞음). 앨범 지도의 색칠은 없어진다.
- `/tastes/` 주소는 그대로 두고 화면 이름만 추억으로.
- 빠른 추가 메뉴에서 "취향" 을 "순간" 과 "기록" 둘로 나눈다.
- 사진에서 위치를 가져오면 그 사진은 그 장소에 직접 연결된다.
