# 메모 (버킷리스트·여행계획) 설계

2026-11-22 · 상태: 검토 반영, 승인 대기 · 앞: 캘린더 날짜 팝업 · 다음: 1년 리캡(후순위)

## 왜

두 사람이 **버킷리스트**와 **여행계획**을 함께 적어 두고 싶다. 모양은 **아이폰 메모장**처럼: 폴더 → 메모 목록 → 메모, 메모 안에 체크 항목. 사용자는 주로 크롬을 쓴다.

## 사용자가 정한 것

- 들어가는 길: 홈 "메모" 카드 + 아래 + 메뉴 "메모".
- 둘이 함께 보고 고친다(개인 메모 없음).
- 폴더: 처음 "버킷리스트"·"여행계획" 두 개, 더 만들 수 있음.
- 메모 안 체크 항목(☐/☑) 쓸 수 있음. 글만(사진 없음).
- 편집 방식 **B**: 아이폰처럼 쓰는 칸 안에 체크 동그라미가 그림으로 보이고 쓰는 중에도 바로 눌러짐.

## 목표

1. **폴더 화면** `/memos/`: 폴더 목록(이름·메모 수), "새 폴더". 맨 위 최근 메모 몇 개는 하지 않음(홈 카드가 그 역할).
2. **메모 목록** `/memos/f/<폴더>/`: 아이폰처럼 제목(첫 줄, 굵게)·고친 날짜·둘째 줄 미리 보기, 최근 고친 순. 아래 "새 메모" 버튼.
3. **메모 쓰기** `/memos/<id>/`: 첫 줄은 제목 모양(크고 굵게). 아래 도구줄에 체크 버튼(지금 줄을 체크 항목 ↔ 글로). 체크 동그라미를 누르면 ☑ + 글에 줄 긋기·흐리게. 쓰는 동안 저절로 저장.
4. **홈 카드**: "메모" — 최근 고친 메모 3개(제목·폴더), 누르면 그 메모, "전체 보기" → 폴더 화면.
5. **+ 메뉴 "메모"**: 새 메모를 "버킷리스트"(또는 마지막으로 쓴 폴더)에 바로 열기.

## 하지 않는 것

- 사진·그림·표·글자 꾸미기(굵게 등), 메모 잠금, 공유 링크, 메모 검색(나중), 끌어서 순서 바꾸기.

## 이러면 실패

- 두 사람이 같은 메모를 동시에 고쳐 한쪽 글이 말없이 사라진다.
- 아이폰에서 쓰다가 커서가 튀거나 체크가 지워진다 (※ 아이폰 크롬도 엔진은 사파리와 같다 — 아이폰을 쓰면 사파리 문제를 그대로 겪는다).
- 붙여 넣은 글에 스크립트·서식이 섞인다.
- 빈 메모가 계속 쌓인다.
- 다른 커플 메모가 보인다.

## 제약

- 새 앱 `memos`, 마이그레이션 `memos.0001_initial` → Neon 확인 숫자 **55**.
- 문구 존댓말, 색 토큰, 375px·라이트/다크·배/여정. 라이브러리 더하지 않음(바닐라 contenteditable).

## 방법 (고려한 것)

| 질문 | 고른 것 | 다른 길 |
|---|---|---|
| 편집 | **B. 쓰는 칸 안에 체크 그림** (사용자) | A. 보기/쓰기 나누기: 단순·안정, 쓰는 중엔 ☐ 글자 |
| 저장 형식 | **줄 목록 JSON** `[{"t":"text"|"check","on":bool,"s":"글"}]` (내 판단) | HTML 저장: 붙여 넣기·스크립트 걸러내기가 어렵고 어긋남 |
| 동시 고침 | **버전 번호: 저장할 때 내 버전이 옛것이면 409, "상대가 먼저 고쳤어요" + 새 내용 불러오기** (내 판단) | 나중 저장이 덮어씀: 말없이 사라짐 |
| 폴더 지우기 | **메모가 있으면 못 지움** (내 판단) | 메모 같이 지움: 실수로 다 사라짐 |

## 설계

### 저장 (앱 `memos`)

- `MemoFolder(couple FK, name Char 20, created_at)`, `(couple, name)` 유일, 이름 순(기본 두 개는 만든 순서대로 위). 커플이 메모 화면에 처음 들어올 때 "버킷리스트"·"여행계획"을 만든다.
- `Memo(couple FK, folder FK PROTECT, lines JSONField, title Char 100, preview Char 120, version PositiveInteger, created_by, updated_by FK SET_NULL, created_at, updated_at)`. 정렬 `-updated_at`.
- `lines` 검사: 목록, 줄 2000개 이하, 각 줄 `t ∈ {text, check}`, `on` bool, `s` 문자열 1000자 이하, 전체 글 20000자 이하. `title` = 첫 줄 글(빈 줄 건너뜀), `preview` = 둘째 글 있는 줄(체크면 "☐ "/"☑ " 붙임).

### 주소

- `GET /memos/` `memos`: 폴더 목록.
- `GET|POST /memos/folders/new/`, `/memos/folders/<pk>/edit/`, `POST /memos/folders/<pk>/delete/` (메모 있으면 거절: "메모를 옮기거나 지운 뒤에 지울 수 있어요.").
- `GET /memos/f/<pk>/` `memo_folder`: 메모 목록.
- `GET /memos/new/?folder=<pk>` `memo_new`: 빈 메모를 만들고 쓰기 화면으로(폴더 없으면 첫 폴더). 
- `GET /memos/<pk>/` `memo_edit`: 쓰기 화면(초기 `lines`·`version` 을 JSON 으로 페이지에).
- `POST /memos/<pk>/save/` `memo_save` JSON `{"lines": [...], "version": n}` → 200 `{"ok": true, "version": n+1, "title", "updated"}`; 버전이 다르면 409 `{"ok": false, "lines": 서버 것, "version": 서버 것}`; 검사 실패 400.
- `POST /memos/<pk>/move/` (폴더 바꾸기), `POST /memos/<pk>/delete/`.
- 빈 메모(글이 하나도 없음)는 쓰기 화면을 떠날 때 지운다(`memo_save` 에 `{"lines": [], "leave": true}` → 삭제, 또는 목록 화면이 글 없는 메모를 지움).
- 모두 내 커플만(404).

### 쓰기 화면 (`static/js/memo-editor.js`)

- `<div class="memo-editor" contenteditable>` 안에 줄마다 `<div class="ln">` 또는 `<div class="ln check [on]"><button class="tick" contenteditable="false" aria-label="체크">` + 글. 첫 줄 `ln:first-child` 는 제목 모양.
- 도구줄(자판 위·화면 아래 고정): 체크 버튼(지금 줄 체크 ↔ 글), 완료(자판 내리기).
- 엔터: 체크 줄에서 엔터 → 새 체크 줄. 빈 체크 줄에서 엔터 → 글 줄로(아이폰처럼). 줄 맨 앞 지우기(백스페이스) on 체크 줄 → 글 줄로.
- 붙여 넣기: 글만(`text/plain`), 줄바꿈마다 줄.
- 저장: 고칠 때마다 0.8초 뒤, 화면을 떠날 때(`pagehide`, `visibilitychange`) `sendBeacon`/fetch keepalive. 저장 중·저장됨 작은 표시.
- 409: "상대가 먼저 고쳤어요. 새 내용을 불러왔어요." + 서버 내용으로 다시 그림(내 마지막 글은 잃지 않게 안내 안에 "내 글 복사" 버튼).
- DOM → 줄 목록 변환은 한 함수(`serialize`), 줄 목록 → DOM 은 `render`. 브라우저가 만든 `<br>`·`<span>`·중첩 `div` 는 `serialize` 가 글로 정리.

## 빌더에게 맡기는 것

- 폴더·목록·쓰기 화면 세부 모양(아이폰 메모장 느낌: 노란 강조 대신 `--primary`), 도구줄 위치.
- 빈 메모 정리 방식(떠날 때 지우기 vs 목록에서 지우기) 중 하나.
- 마지막으로 쓴 폴더 기억(세션 또는 기기 저장소), 떠날 때 저장의 CSRF 처리(fetch keepalive + X-CSRFToken), 저장 요청 겹침(한 번에 하나, 나머지는 끝난 뒤 최신 것만), 떠날 때 저장이 409 면 서버 것을 두고 내 글은 버리지 않게(다음에 열 때 안내), 폴더 옮기기 화면(메모 화면의 작은 메뉴). (검토에서 나온 것, 내 판단)

## 내가 정한 것 (사용자 확인 필요)

- 줄 목록 JSON 으로 저장(HTML 아님).
- 동시에 고치면 "상대가 먼저 고쳤어요" 와 새 내용, 내 글은 복사 버튼으로 남김.
- 메모가 든 폴더는 못 지움. 기본 폴더 두 개도 이름 바꾸기·지우기 가능(메모가 없을 때).
- + 메뉴 "메모" 는 마지막으로 쓴 폴더(없으면 버킷리스트)에 새 메모.
- 빈 메모는 남기지 않음.
