# 캘린더 날짜 팝업으로 일정 추가 설계

2026-11-22 · 상태: 승인 대기 · 앞: 위·아래 색 맞추기 · 다음: 메모(버킷리스트·여행계획)

## 왜

지금은 "일정 추가" 버튼이 따로 있고, 폰에서 날짜를 누르면 아래 목록이 그날로 바뀐다. 사용자는 **날짜를 누르면 그 날짜에 일정을 추가하는 팝업**이 뜨길 원한다. 폰에서는 꾹 눌러도 팝업. 버튼이 사라지는 만큼 폰 달력을 키워 칸에 일정 이름까지 보이게 한다.

## 사용자가 정한 것

- 폰: 날짜를 **누르거나 꾹 누르면** 추가 팝업. 그날 일정은 팝업 위쪽에.
- 데스크톱: 날짜를 누르면 추가 팝업.
- 폰 달력 칸을 키워 **일정 이름 두 줄 + "+N"** (데스크톱 큰 달력처럼).
- 방법 A: 누를 때 서버에서 팝업 내용(그날 일정 + 빠른 추가 칸)을 받아 온다.

## 목표

1. 팝업: 폰은 아래에서 올라오는 판(바텀시트), 데스크톱은 가운데 창. 네이티브 `<dialog>`.
2. 팝업 안: 제목 "11월 25일 (화)", 그날 일정 목록(누르면 고치기 화면), 빠른 추가 칸 — 일정(@ # 포함), 하루 종일·시작·끝, 끝나는 날, 공통/개인 — 와 "추가" 버튼, "자세히 쓰기 ›"(지금의 일정 추가 화면, 날짜·적은 글 넘김).
3. 저장하면 그 달 그 날로 캘린더를 다시 불러온다. 잘못 넣으면 팝업 안에 오류.
4. "일정 추가" 버튼 지우기(폰 목록 머리, 데스크톱 큰 달력 머리). + 메뉴 "일정"은 남김.
5. 폰 달력 칸: 데스크톱 큰 달력의 조각(lane) 막대를 폰에도 — 이름 두 줄 + "+N". 칸 높이 고정.
6. 폰 달력 아래 목록은 늘 "다가오는 일정".

## 하지 않는 것

- 팝업에서 일정 고치기·지우기(목록을 누르면 지금의 고치기 화면).
- 팝업 안 메모·색·장소 칸(자세히 쓰기에서).
- 지난 날짜 막기(지금처럼 지난 날짜에도 추가 가능).

## 이러면 실패

- 스크립트가 없거나 팝업 주소가 실패하면 아무것도 못 한다 → 칸 링크는 그대로 일정 추가 화면(`?date=`)을 가리켜, 스크립트 없이도 동작.
- 데스크톱 큰 달력에서 끌어서 옮기기가 팝업 때문에 깨진다(끄는 동안 누름으로 처리되면 안 됨).
- 꾹 누를 때 폰 기본 메뉴(링크 미리보기·복사)가 뜬다.
- 팝업 저장 뒤 다른 달로 튄다.

## 방법 (고려한 것)

| 질문 | 고른 것 | 다른 길 |
|---|---|---|
| 팝업 내용 | **A. 누를 때 서버에서 받아 오기** (사용자) | B. 화면에 미리 다 넣기: 기다림 없음, 폼·오류 처리를 화면 쪽에서 다시 만들어야 함 |
| 팝업 틀 | **`<dialog>` 하나를 캘린더 화면에 두고 내용만 바꿈** (내 판단) | 새 창 화면: 팝업이 아님 |
| 저장 | **fetch POST, 성공이면 JSON 으로 이동 주소, 실패면 팝업 HTML 다시** (내 판단) | 보통 폼 제출: 오류 때 전체 화면으로 넘어감 |

## 설계

- `GET /calendar/day/<YYYY-MM-DD>/` `day_popup` (로그인): 팝업 HTML 조각(레이아웃 없음). 그날에 걸친 내가 볼 수 있는 일정(여러 날 포함, 시작 시간 순) + `QuickEventForm`(EventForm 에서 장소·메모·색 뺀 것, 날짜는 숨은 칸). 잘못된 날짜 404.
- `POST` 같은 주소: 검사 통과 → `services.save_event`(장소·메모 빈 값, 색 기본 sky) → `{"ok": true, "url": 캘린더 주소(그 달, 그 날)}`. 실패 → 400 과 오류가 든 같은 조각 HTML.
- "자세히 쓰기": `event_create?date=<날>&text=<적은 글>` (일정 추가 화면이 `text` 초기값을 받게).
- 캘린더 칸(폰 `.day`, 데스크톱 `.cell`): `href` 는 `event_create?date=`(스크립트 없을 때), `data-day-popup="<날>"`. JS(`calendar-popup.js`): 누름 → 팝업 열고 `day_popup` 받아 넣기. 꾹 누름(500ms, `contextmenu` 막기, `-webkit-touch-callout: none`)도 같음. 데스크톱 끌기 중에는 열지 않음(끌기가 끝난 직후 클릭 무시).
- 폰 달력 칸: 뷰가 만든 `cell.pieces`/`cell.more` 를 폰 칸에도 그린다(이름 10px, 막대 16px). 칸 높이 고정(예: 78px).
- 지우기: 폰 `list-head` 의 "일정 추가", 데스크톱 `.cal-controls .add`. 폰 목록은 `upcoming`.

## 빌더에게 맡기는 것

- 팝업 세부 모양, 폰 칸 높이·글자 크기, 팝업 여닫는 움직임.

## 내가 정한 것 (사용자 확인 필요)

- 팝업의 빠른 추가는 이름·시간·끝나는 날·공통/개인만. 나머지는 "자세히 쓰기".
- 저장하면 그 달 그 날로 다시 불러와 새 일정이 칸에 보인다.
- 폰 달력 아래는 늘 "다가오는 일정"(날짜를 눌러 목록을 바꾸는 방식은 없어짐).
