# 다녀온 곳 색칠 지도 설계

2026-11-17 · 상태: 검토 반영, 승인 대기 · 이어지는 것: 가고 싶은 곳 저장(2), 1년 리캡(3) — 각각 따로 설계

## 왜

두 사람이 함께 다녀온 곳을 마이코리아맵처럼 지역 단위로 채워 가는 "색칠판"으로 보고 싶다. 특히 서울에서 많이 만나므로 서울은 동 단위까지 자세히 본다. 장소 핀 지도(실제 지도)와는 다른, 한눈에 "얼마나 채웠나" 를 보는 화면이다.

## 목표

- 추억 › 기록 안에 `핀 지도 · 색칠 지도` 전환. 색칠 지도는 실제 지도 타일 없이 **경계만 그린 SVG 지도**.
- 단계: **전국**(시·군·구 250곳) → **서울**(25개 구) → **구**(그 구의 행정동). 위쪽에 `전국 › 서울 › 성동구` 경로, 누르면 그 단계로.
- 칠해지는 기준: **자동 + 직접**.
  - 자동: 위치 있는 기록 장소, 위치 있는 앨범 사진이 그 지역 안에 있으면 칠해진다.
  - 직접: 지역을 누르면 아래 칸에 이름과 근거("장소 2곳 · 사진 5장")가 나오고, `칠하기` / `지우기` / `자동으로` 를 고른다. 직접 정한 것이 자동보다 먼저다.
- 요약: 전국 "시·군·구 N/250", 서울 "구 N/25 · 동 N/423", 구 "동 N/M".
- 색은 테마 토큰을 따른다(배·여정, 라이트·다크).

## 하지 않는 것

- 가고 싶은 곳(노랑) 표시 — 다음 설계(가고 싶은 곳 저장)에서 핀으로 따로.
- 서울 밖의 동 단위, 해외 색칠, 공유 이미지 만들기, 통계 화면(리캡에서).
- 실제 지도(카카오/OSM) 위에 덮어 칠하기.

## 이러면 실패 (기술적으로 동작해도)

- 폰에서 서울 동 지도(423개)가 버벅이거나 눌러지지 않는다.
- 직접 지운 지역이 새 사진을 올리면 다시 칠해진다.
- 다른 커플의 장소·사진·표시가 섞인다.
- 과금 (외부 지도·API 를 부르지 않는다).

## 제약

- 경계 데이터는 앱에 넣는다(`static/geo/`). 외부 지도·API 는 부르지 않는다 (topojson-client 라이브러리만 기존처럼 jsdelivr 에서).
  - 전국 시·군·구: 이미 있는 `kr-municipalities-2018.topo.json` (KOSTAT 2018, 250곳, 서울 25개 구 포함).
  - 서울 행정동: 새로 `seoul-dongs-2013.topo.json` — [southkorea/seoul-maps](https://github.com/southkorea/seoul-maps) `kostat/2013/json/seoul_submunicipalities_topo_simple.json` (KOSTAT 2013, 423개 동, 98KB). 2013년 이후 나뉘거나 합쳐진 동은 옛 경계로 보인다.
- 모델이 바뀐다 → Neon migrate 를 배포보다 먼저.
- 사진·장소 위치는 커플 두 사람만.

## 방법 (고려한 것)

| 방법 | 장점 | 단점 |
|---|---|---|
| **경계만 그린 SVG 색칠판 (선택)** | 색칠판 느낌, 테마 색, 누르기 쉬움, 가볍고 외부 사용량 없음, 단계 들어가기 쉬움 | 실제 길·건물이 없어 위치감은 이름·모양으로만 |
| 실제 지도 위에 다각형 덮기 | 위치를 알기 쉬움 | 동 423개 덮으면 지저분·무거움, 길 가림, 누르기와 끌기가 겹침 |

사용자가 SVG 색칠판을 골랐다. 서울은 동 단위까지, 칠하기는 자동 + 직접.

## 설계

### 저장 (마이그레이션 → Neon)

- `RegionMark(couple, level, code, state, updated_by, updated_at)`
  - `level`: `"sigungu"` (KOSTAT 2018 시·군·구 코드, 예 `11040`) 또는 `"dong"` (KOSTAT 2013 동 코드, 예 `1104065`).
  - `state`: `"on"`(직접 칠함) / `"off"`(직접 지움). "자동으로" 는 행을 지운다.
  - `(couple, level, code)` 유일. 코드는 숫자 4~10자리만 받는다.

### 자동 칠하기 (브라우저)

- 데이터 `GET /tastes/regions/data/` (로그인, 내 커플): `{"points": [{"lat","lng","kind":"place"|"photo"}], "marks": [{"level","code","state"}]}`. 장소는 위치 있는 기록 장소, 사진은 위치 있는 앨범 사진. 이름·주소·사진 주소는 넣지 않는다(지역 판정에 필요 없음).
- 브라우저가 경계 파일을 받아 점마다 들어 있는 시·군·구, (서울이면) 동을 찾는다(기존 map.js 의 점-다각형 검사 재사용). 지역마다 장소 수·사진 수.
- 칠해짐 = `mark == "on"` 이거나 (`mark != "off"` 이고 장소·사진이 1개 이상).
- **서울 구와 동의 관계**: 동은 동대로 판정한다(동 다각형 안의 점, 동 표시). 구는 `구 표시 == "on"` 이거나 (`구 표시 != "off"` 이고 (구 다각형 안에 점이 있거나 **칠해진 동이 하나라도 있으면**)). 구를 칠하거나 지워도 그 안의 동은 따라가지 않는다. 그래서 동만 직접 칠해도 구·전국 색과 "구 N/25" 에 반영된다.
- 점 세기: 장소는 장소 좌표, 사진은 사진 자신의 좌표로 각각 센다 (장소에 붙은 사진도 사진 1장으로 따로 센다). 어느 지역에도 안 드는 점(해외·바다)은 버린다.
- 동이 어느 구에 속하는지는 동 다각형의 대표점(첫 고리 평균점)이 든 구로 정한다 (2013 동 코드와 2018 구 코드 체계가 달라서).

### 직접 칠하기

- `POST /tastes/regions/mark/` (로그인, CSRF) JSON `{"level","code","state":"on"|"off"|"auto"}` → `{"ok": true}`. `auto` 는 표시를 지운다.
- 화면은 저장 응답 전에 바로 칠해 보이고, 실패하면 되돌리고 "저장하지 못했어요" 를 보인다.

### 화면

- 기록 탭 위 전환 `핀 지도 · 색칠 지도` (기본: 핀 지도, 마지막 고른 것을 기기에 기억 — localStorage, 없어도 동작).
- 색칠 지도 칸: 경로(`전국 › 서울 › 성동구`), 요약 한 줄, SVG 지도(정사각형에 가깝게, 폰 너비에 맞춤, 두 손가락 확대 없음 — 단계로 들어가는 방식), 아래 지역 칸.
- 전국: 시·군·구 250곳(서울 25개 구와 일반구 — 수원시장안구 등 — 를 각각 한 곳으로). 서울 구들도 각자 칠해 보이지만 작아서 **서울 안 어디를 눌러도 서울 단계로** 들어간다(전국 단계에서 서울 구를 따로 고를 수 없다). 전국 "시·군·구 N/250" 의 N 에는 서울 구도 들어간다. 시·도 경계는 굵게, 지역 이름은 칠해진 곳만 작게.
- 서울: 25개 구, 이름 모두 표시. 구를 누르면 아래 칸에 구 정보 + `동까지 보기`.
- 구: 그 구의 동들, 이름 모두 표시, 동을 누르면 아래 칸. 서울·구 단계 아래에 작은 안내 "동 경계는 2013년 기준이라 그 뒤 새로 생긴 동은 옛 동에 칠해질 수 있어요".
- 아래 지역 칸: 이름(시·도를 붙인다: "부산 중구", "서울 성동구", 동은 "성동구 성수1가1동". 시·도 이름은 코드 앞 두 자리 대응표 — 11 서울 … 39 제주), 근거("장소 2곳 · 사진 5장" 또는 "기록 없음"), 상태 버튼 셋(`칠하기` `지우기` `자동으로`, 지금 상태 강조).
- 색: 칠해진 지역 `--primary` 계열(직접 칠한 곳과 자동은 같은 색), 안 칠한 곳 `--tile`, 경계 `--surface` 대비 선, 고른 지역은 테두리 강조. 다크 모드에서도 대비 확인.

### 지도 그리기

- 투영: 위도 중심의 등장방형(경도 × cos(중심 위도)) — 한국·서울 범위에서는 충분. 단계마다 그 범위에 맞춰 viewBox.
- topojson-client 로 피처를 만들고 SVG `path` 를 직접 만든다(d3 없이). 단계마다 한 번만 만들고 다시 쓴다.
- 경계 파일은 색칠 지도를 처음 열 때만 받는다(동 파일은 서울 단계를 처음 열 때).

## 빌더에게 맡기는 것

- SVG 레이아웃 크기, 글자 크기·겹침 처리(작은 지역 이름 생략), 아래 칸 모양.
- 선 단순화 추가 여부(지금 파일로 폰에서 매끄러우면 그대로).

## 내가 정한 것 (사용자 확인 필요)

- 동이 칠해지면 그 구도 칠해진다(반대로 구를 칠해도 동은 그대로).
- 장소에 붙은 사진도 사진 1장으로 따로 센다. 해외·바다 위 점은 색칠에 쓰지 않는다.
- 지역 이름에 시·도를 붙인다 ("부산 중구").
- 서울·구 단계에 "동 경계는 2013년 기준" 안내를 둔다.

- 동 경계는 2013년 자료 (작고 바로 쓸 수 있음). 나중에 필요하면 최신 자료로 바꾼다.
- 전국 단계에서는 서울을 통째로 눌러 서울 단계로 들어간다.
- 직접 칠한 곳과 자동으로 칠해진 곳은 같은 색.
- 기록 탭의 기본 보기는 핀 지도, 마지막에 고른 보기를 기기에 기억.
