# 화면 문구 조사표와 통일안 (2026-11-25)

화면에 보이는 글자·버튼·안내 문구를 모아 같은 뜻인데 다르게 쓴 말을 찾았다. 괄호 숫자는 쓰인 곳 수.

## 1. 고치는 말 — '고치기'(14) · '수정'(2) · '바꾸기'(5)

| 지금 | 쓰인 곳 |
|---|---|
| 고치기 | 일정 고치기, 순간 고치기, 장소 고치기, 사진 고치기, 이름표 고치기, 폴더 고치기, 목록 고치기, 가고 싶은 곳 고치기, (사진·순간 화면 버튼) 고치기 |
| 수정 | 기념일 수정, 프로필 수정 |
| 바꾸기 | 프로필 바꾸기, 앨범 이름 바꾸기, (장소 고르기) 바꾸기, (추억 누가 버튼) 눌러서 바꾸기 |

**통일안: '수정'** — 버튼은 `수정`, 화면 제목은 `일정 수정`·`폴더 수정`… 프로필·앨범 이름도 `수정`.
단, 다른 것으로 갈아 끼우는 뜻인 장소 `바꾸기`, 추억 누가 버튼의 `바꾸기`는 그대로.

## 2. 없애는 말 — '지우기'(11) · '삭제'(2) · '빼기'(2)

| 지금 | 쓰인 곳 |
|---|---|
| 지우기 | 일정·메모·폴더·앨범·이름표·목록·댓글 지우기, 사진·순간·가고 싶은 곳·색칠 지도 지우기 / 확인 "이 ○○을 지울까요?" 12곳 |
| 삭제 | 기념일 삭제, "이 기념일을 삭제할까요?" |
| 빼기 | 프로필의 사진 빼기, 이모지 빼기 |

**통일안: '삭제'** — '수정'과 짝. 버튼 `삭제`, `일정 삭제`, 확인 "이 일정을 삭제할까요?".
프로필 `빼기`(지우는 게 아니라 프로필에서 빼는 것)와 색칠 지도의 `지우기`(칠한 색을 지움)는 그대로.

## 3. 만드는 말 — 추가(20) · 만들기(8) · 새 ○○(14) · 남기기 · 올리기 · 쓰기

| 지금 | 쓰인 곳 |
|---|---|
| ○○ 추가 | 일정 추가, 기념일 추가 |
| 새 ○○ / 만들기 | 새 폴더, 새 목록, 새 이름표 (버튼은 만들기) |
| 남기기 · 올리기 · 쓰기 | 순간·기록 남기기, 사진 올리기, 메모 쓰기 |

**통일안: 지금 그대로** — 일정·기념일은 `추가`, 담는 그릇(폴더·목록·태그)은 `새 ○○`/`만들기`, 순간·사진·메모는 그 물건에 맞는 말(남기기·올리기·쓰기)이 자연스럽다.
'일정 만들기'(캘린더 글로 일정 버튼 이름) 1곳만 `일정 추가`로.

## 4. 모아 보는 말 — '전체 보기'(2) · '모두 보기'(2)

**통일안: '전체 보기'** — 캘린더 태그 목록의 '모두 보기', 지도 카드의 '모두 보기 ›' → `전체 보기`.

## 5. 이름표 → 태그 (12곳)

지금은 `@카테고리`와 `#태그`를 묶어 '이름표'라 부르고, 이름표 관리 화면 안에서는 다시 '카테고리'·'태그'로 나눈다. 묶는 말을 '태그'로 바꾸면 `#태그`와 이름이 겹친다.

| 안 | 묶는 말 | @ | # |
|---|---|---|---|
| **A (추천)** | 태그 | 카테고리 | 해시태그 |
| B | 태그 | 분류 | 태그 |

**추천 A** — '이름표 관리' → `태그 관리`, '이름표 만들기' → `태그 만들기`, '이름표로 모아 보기' → `태그로 모아 보기`. 관리 화면 안의 두 묶음은 `카테고리 (@)`, `해시태그 (#)`.

## 6. 그대로 둘 것

닫기·취소·완료·저장, 연결 끊기, 확인 문구의 "되돌릴 수 없어요" 같은 안내.
