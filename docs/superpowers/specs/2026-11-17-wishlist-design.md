# 가고 싶은 곳 저장 + 기록 화면 정리 설계

2026-11-17 · 상태: 검토 반영, 승인 대기 · 앞: 색칠 지도(1) · 다음: 1년 리캡(3)

## 왜

데이트를 계획할 때 "가고 싶은 곳" 을 네이버 지도의 저장처럼 모아 두고, 두 사람이 직접 만든 목록(여행·맛집·카페·○○ 데이트…)으로 나눠 보고 싶다. 다녀오면 그게 기록이 되어 사진·색칠 지도·리캡으로 이어진다. 함께, 기록 화면에 전환 칸이 세 줄 쌓인 것을 정리한다.

## 목표

- **가고 싶은 곳 저장**: 장소(이름·위치·주소·링크·한 줄 메모)를 저장하고, 두 사람이 만든 **목록**에 넣는다. 한 장소를 여러 목록에 넣을 수 있다. 목록마다 색 하나.
- **다녀왔어요**: 누르면 그 장소로 **기록 장소(분류 "장소" 글)** 를 만들고(근처 사진 자동 연결·색칠 지도 반영), 가고 싶은 곳은 목록에 **"다녀옴"** 표시로 남는다.
- **들어가는 길**: 기록 탭의 장소 목록 위 카드 `♡ 가고 싶은 곳 · N곳 ›` → 가고 싶은 곳 화면. (추억에 칸을 늘리지 않는다.)
- **가고 싶은 곳 화면**: 목록 칩(전체 · 목록들 · `+ 새 목록`), 지도(핀은 목록 색, 다녀온 곳은 체크 핀), 저장한 곳 목록, `가고 싶은 곳 저장` 버튼.
- **기록 핀 지도에 겹쳐 보기**: 지도 카드 아래 칩 `가고 싶은 곳도 보기` (핀 지도에서만). 켜면 가고 싶은 곳이 목록 색의 빈 핀으로.
- **기록 화면 정리**: 큰 전환은 `순간 · 기록` 하나만.
  - `핀 지도 · 색칠 지도` → 지도 카드 오른쪽 위 작은 아이콘 버튼 두 개(핀/붓).
  - `국내 · 해외` → 지도 카드 왼쪽 위 작은 칩. 색칠 지도에서는 이 자리에 `전국 › 서울 › 구` 경로.
  - 요약 한 줄은 지도 카드 아래로.

## 하지 않는 것

- 목록 공유(커플 밖), 목록 순서 끌어 바꾸기, 알림, 네이버 지도에서 가져오기.
- 다녀온 뒤 가고 싶은 곳을 자동으로 지우기 (남겨 둔다).

## 이러면 실패

- 다른 커플의 목록·장소가 보인다.
- 목록을 지웠는데 그 안의 장소가 같이 사라진다 (장소는 남고 목록에서만 빠져야 한다).
- "다녀왔어요" 를 두 번 눌러 기록이 둘 생긴다.
- 정리한 뒤 지도 카드 위 버튼이 폰에서 너무 작아 못 누른다 (최소 36px).

## 제약

- 모델이 바뀐다 → Neon migrate 먼저 (확인 숫자 51).
- 위치 정하기는 기존 장소 고르기(검색·지도에서 찍기) 재사용. 사진에서 가져오기는 가고 싶은 곳에는 없다 (아직 안 간 곳).
- 지도는 기존 `map.js`(국내 카카오맵/해외 Leaflet) 재사용.

## 방법 (고려한 것)

| 질문 | 고른 것 | 다른 길 |
|---|---|---|
| 다녀오면 | **기록으로 만들고 목록에도 "다녀옴"** (사진·색칠·리캡과 이어짐) | 목록에 체크만: 단순하지만 따로 놂 |
| 어디서 | **기록 안 카드 → 가고 싶은 곳 화면** + 핀 지도 겹쳐 보기 칩 | 추억 세 번째 칸: 칸이 많아짐 / 핀 지도 칩만: 목록 관리가 불편 |
| 화면 정리 | **지도 카드 안 작은 버튼으로** | 그대로 세 줄 |

모두 사용자가 고른 것이다.

## 설계

### 저장 (마이그레이션 → Neon)

- `WishList(couple, name ≤20, color ∈ COLOR_CHOICES, created_by, created_at)`, `(couple, name)` 유일.
- `WishPlace(couple, name ≤100, latitude, longitude, address ≤200, place_url, link, memo ≤300, lists M2M WishList blank, created_by, created_at, visited_at null, visited_place FK Taste null SET_NULL)`.
  - 위치는 꼭 있어야 한다 (가고 싶은 곳은 지도에 찍는 것이 핵심).
  - "다녀옴" = `visited_at` 이 있음. 기록 장소를 지워도 "다녀옴" 은 남는다.
  - 가고 싶은 곳·목록·"다녀옴" 은 커플이 함께 쓴다. 한 사람이 "다녀왔어요" 를 누르면 두 사람 모두에게 다녀옴으로 보인다 (사용자 확인).

### 주소와 화면

- `GET /tastes/wishes/` (`?list=<id>`): 가고 싶은 곳 화면. 다녀오지 않은 것 먼저, 최근 순.
- `GET|POST /tastes/wishes/new/`, `/tastes/wishes/<pk>/edit/`, `POST /tastes/wishes/<pk>/delete/`: 저장·고치기·지우기. 폼: 이름, 위치(장소 고르기 — 검색·지도에서 찍기), 목록(체크, 그 자리에서 `새 목록 이름` 칸으로 하나 만들기), 링크, 한 줄 메모.
- `POST /tastes/wishes/<pk>/visited/`: 다녀왔어요 — `transaction.atomic` + `select_for_update` 로 그 행을 잠그고, 기록 장소(`visited_place`)가 아직 있으면 그리로 이동만(두 번 눌러도 하나). 다녀온 뒤 기록 장소를 지워 `visited_place` 가 비었으면 새로 만든다("다시 기록하기"). 아니면 기록 장소를 만들고(이름·위치·주소·장소 링크·링크, 한마디는 비움) `visited_at`, `visited_place` 를 남긴 뒤 사진 연결을 다시 계산하고, 새 기록 장소 화면으로.
- 폼의 `새 목록 이름` 이 이미 있는 목록 이름과 같으면(앞뒤 공백 무시) 그 목록에 넣는다(새로 안 만든다). 목록에서 장소를 빼는 것은 장소 고치기에서 체크를 끄는 것으로만.
- 색: 목록 색은 `COLOR_CHOICES` 토큰 이름(sky·rose·sand·lav·sage·peach)을 저장하고, 화면·지도 핀은 `var(--<색>)` 을 읽어 쓴다(테마·모드에 따라 바뀜).
- 목록: `POST /tastes/wishes/lists/new/` (이름·색), `/tastes/wishes/lists/<pk>/edit/` (이름·색), `/tastes/wishes/lists/<pk>/delete/` (장소는 남는다).
- `GET /tastes/wishes/data/`: 지도용 `[{id, name, lat, lng, color, visited, url}]` (color = 첫 목록(이름순) 색 이름, 목록 없으면 `peach`). `?open=1` 이면 다녀오지 않은 것만 (기록 지도 겹쳐 보기용: 다녀온 곳은 이미 기록 핀이 있다).
- 국내/해외는 기록 지도와 같이 **좌표로** 판정한다(`map.js` 의 같은 함수). 저장 칸은 두지 않는다.
- 기록 탭: 장소 목록 위 카드 `가고 싶은 곳 · N곳` (다녀오지 않은 것 수).

### 지도

- 가고 싶은 곳 화면의 지도: `map.js` 의 기록 지도를 데이터 주소·핀 모양만 바꿔 재사용 (핀 = 목록 색 채운 원, 다녀옴 = 체크 표시). 국내·해외 칩 그대로.
- 기록 핀 지도의 `가고 싶은 곳도 보기`: 켜면 `/tastes/wishes/data/` 를 받아 빈 핀(테두리만 목록 색)으로 겹친다. 카드에 "가고 싶은 곳" 표시. 기기에 기억.

### 기록 화면 정리

- 지도 카드(`.map-canvas` 를 감싼 카드) 안 위쪽에 겹치는 조작줄: 왼쪽 `국내 · 해외` 작은 칩(색칠 지도에서는 경로), 오른쪽 핀/붓 아이콘 버튼(최소 36×36px, `aria-pressed`, 이름 "핀 지도"/"색칠 지도").
- 색칠 지도도 같은 카드 틀 안에 들어간다. 요약 한 줄은 카드 아래.

## 빌더에게 맡기는 것

- 핀 아이콘 모양, 목록 색 고르기 모양, 가고 싶은 곳 카드 모양.
- 지도 조작줄이 카카오맵·Leaflet 조작 버튼과 겹치지 않게 자리 잡기.

## 내가 정한 것 (사용자 확인 필요)

- "다녀왔어요" 는 두 번 눌러도 기록이 하나. 다녀온 기록 장소를 지웠다면 다시 누를 때 새로 만든다.
- 기록 지도에 겹쳐 볼 때는 아직 안 다녀온 곳만 보인다.
- 새 목록 이름이 이미 있으면 그 목록에 넣는다.

- 한 장소를 여러 목록에 넣을 수 있다. 목록마다 색 하나, 지도 핀은 첫 목록 색.
- 가고 싶은 곳은 위치가 꼭 있어야 한다. 사진에서 가져오기는 없다.
- 다녀온 뒤에도 가고 싶은 곳은 지우지 않고 "다녀옴" 으로 남긴다. 다녀온 기록 장소를 지워도 "다녀옴" 은 남는다.
- 목록을 지우면 장소는 남고 그 목록에서만 빠진다.
- 기록 탭 카드의 숫자는 아직 안 다녀온 곳의 수.
