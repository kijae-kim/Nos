# 가고 싶은 곳 저장 + 기록 화면 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 가고 싶은 곳을 사용자가 만든 목록으로 저장하고, "다녀왔어요" 로 기록 장소가 되게 하며, 기록 화면의 전환 칸을 지도 카드 안 작은 버튼으로 줄인다.

**Architecture:** 새 모델 `WishList`, `WishPlace`(couples 앱). 폼·뷰는 기존 장소 폼/장소 고르기(`place-picker.js`)와 기록 지도(`map.js`)를 재사용. 다녀왔어요는 `WishPlace` 행 잠금 뒤 기록 장소 생성 + `places.relink`.

**Tech Stack:** Django 5.2, 바닐라 JS, 기존 map.js / place-picker.js / coloring-map.js.

**Spec:** `docs/superpowers/specs/2026-11-17-wishlist-design.md`

## Global Constraints

- 문구 존댓말, 주석 한국어, 색은 토큰(`var(--<색>)`). 375px·라이트/다크·배/여정 확인. 지도 카드 위 버튼 최소 36×36px.
- 목록 이름 1~20자, `(couple, name)` 유일. 색 ∈ `COLOR_CHOICES` 이름. 장소 이름 1~100, 주소 ≤200, 메모 ≤300, 위치 필수(`clean_coords`).
- 모든 조회·수정은 내 커플만 (`get_object_or_404(..., couple=)`).
- "다녀옴" 은 장소에 하나(커플 공유). 다녀왔어요는 기록 하나만.
- 마이그레이션 `couples.0013_wishlist` → Neon 확인 숫자 **51**, 배포보다 먼저.
- 테스트 `cd web && ../.venv/bin/python manage.py test`. 브랜치 `feat/wishlist`.

## Review Focus

1. 같은 가고 싶은 곳에 다녀왔어요 두 번 → 기록 하나 (Task 2 테스트).
2. 다른 커플의 목록 pk 를 폼·주소에 넣어도 무시되거나 404 (Task 1 테스트).
3. 목록 지우기 → 장소는 남음 (Task 1 테스트).
4. 다녀온 기록 장소를 지운 뒤 다시 누르면 새로 만듦, "다녀옴" 은 유지 (Task 2 테스트).
5. 375px 에서 지도 카드 위 버튼이 카카오맵·Leaflet 조작 버튼과 겹치지 않음 (Task 3 브라우저 확인).

### Task 2: 다녀왔어요, 지도 데이터, 기록 탭 카드

**Files:** Modify `web/couples/views.py` (`wish_visited`, `wish_map_data`, `taste` 기록 컨텍스트), `urls.py`, `templates/couples/taste.html` (카드); Test `WishVisitedTests`

**Interfaces — Produces:**
- `POST tastes/wishes/<pk>/visited/` `wish_visited`: `transaction.atomic` + `select_for_update` 로 그 행. `visited_place` 있음 → 그 장소 화면으로. 없음 → `Taste(category="장소", title=name, latitude, longitude, address, place_url, link)` 만들기(`author=user`), `visited_place` 설정, `visited_at` 없으면 지금, `places.relink(couple)`, 메시지 "기록으로 옮겼어요. 사진은 근처에서 찍은 것이 저절로 모여요." → 새 장소 화면.
- `GET tastes/wishes/data/` `wish_map_data`: `{"places": [{"id","name","lat","lng","color","visited","url","address","photos":0}]}`, `?list=` 거르기, `?open=1` 이면 다녀오지 않은 것만. `url` = 고치기 화면.
- 기록 탭 컨텍스트 `wish_open_count` (다녀오지 않은 내 커플 수), 카드 `<a class="wish-card card" href="{% url 'wishes' %}">♡ 가고 싶은 곳 · N곳 ›</a>`.
