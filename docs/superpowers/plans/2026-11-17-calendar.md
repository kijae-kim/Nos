# 캘린더 묶음 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 여러 날 일정(하루 종일), 데스크톱 큰 달력에서 끌어서 옮기기, 이름표 관리 화면, 폰 시간 칸 잘림 고치기.

**Architecture:** `Event.end_date` 하나로 여러 날을 표현하고, 기간 쿼리·지난 일정 판정을 모델/쿼리셋에 모은다. 큰 달력은 뷰가 주마다 줄(lane)을 계산해 칸마다 조각을 그린다. 끌기는 HTML 기본 끌어 놓기 + `event_move` JSON. 이름표 관리는 보통 폼 화면.

**Tech Stack:** Django 5.2, 서버 템플릿, 바닐라 JS (`static/js/app.js` 또는 새 `static/js/calendar-drag.js`), `static/css/app.css`.

**Spec:** `docs/superpowers/specs/2026-11-17-calendar-design.md`

## Global Constraints

- 문구 존댓말, 주석 한국어, 색은 토큰. 375px·넓은 화면·라이트/다크·배/여정 확인.
- 마이그레이션 `couples.0014_event_end_date` → Neon 확인 숫자 **52**, 배포보다 먼저.
- 지난 일정 = `last_date < timezone.localdate()` (`last_date = end_date or date`). 지난 일정은 읽기 전용, 지우기만.
- 여러 날 일정은 하루 종일만(시간 None), `end_date > date`, 길이(끝-시작) ≤ 59일(= 60일까지). `end_date == date` 는 None 으로.
- 모든 조회·수정은 `Event.objects.visible_to(user)` / `couple=` 범위.
- 라이브러리를 더하지 않는다.
- 테스트 `cd web && ../.venv/bin/python manage.py test`. 브랜치 `feat/calendar`.

### Task 3: 끌어서 옮기기 (데스크톱)

**Files:** Modify `web/couples/views.py` (`event_move`), `urls.py`, `templates/couples/calendar.html`, `static/css/app.css`; Create `web/static/js/calendar-drag.js` (calendar.html 에서만 로드); Test `EventMoveTests`

**Interfaces:**
- Consumes: Task 1 `is_past`, `span_days`; Task 2 조각의 `data-event-id`.
- Produces: `POST /calendar/events/<pk>/move/` name `event_move` (login, CSRF 헤더 `X-CSRFToken`), 본문 JSON `{"date": "YYYY-MM-DD"}` (새 시작일). 성공 `{"ok": true, "date", "end_date"(없으면 null)}` + Django 메시지(아래). 실패 400 `{"ok": false, "error": <문구>}`: 지난 일정 "지난 일정은 옮길 수 없어요.", 옮긴 뒤 끝나는 날 < 오늘 "지난 날로는 옮길 수 없어요.", 형식·JSON 오류 "옮기지 못했어요. 잠시 뒤 다시 해 볼까요?". 남의 일정·상대 개인 일정 404.
- 성공 메시지: "<n>월 <j>일로 옮겼어요." + 되돌리기 정보(옛 시작일). 되돌리기 결과의 끝나는 날이 오늘 이후일 때만 메시지 안에 되돌리기 버튼(같은 `event_move` 를 옛 날짜로 부르는 작은 폼/버튼, `data-undo-event`, `data-undo-date`). 메시지에 HTML 을 넣지 말고, 캘린더 템플릿이 세션의 `last_move = {"event", "date", "undo_ok"}` 를 한 번 읽어(pop) 버튼을 그린다.
- 칸: `data-drop-date="YYYY-MM-DD"`. 조각: `draggable="true"`(지난 일정 아님), `data-event-id`, `data-grab-date`(그 칸 날짜), `data-start`(시작일), `data-span`(일 수).
- JS: 새 시작일 = 시작일 + (놓은 칸 − 집은 칸). 끄는 동안 새 끝나는 날 < 오늘인 칸은 `.no-drop`(흐림, 놓기 안 됨). 놓으면 POST → 성공 시 같은 달 주소로 다시 불러오기, 실패 시 서버 문구를 잠깐 보여 주기.

- [ ] **Step 1: 실패하는 테스트**: 하루 일정 옮기기 → date 바뀜·시간 그대로; `test_move_multi_day_keeps_length_across_month` (11/29~12/2 를 12/27 로 → 12/27~12/30); 진행 중 여행(어제~내일)을 하루 뒤로 → 됨; 같은 여행을 끝나는 날이 어제가 되게 → 400 "지난 날로는 옮길 수 없어요."; 지난 일정 → 400 "지난 일정은 옮길 수 없어요."; 상대 개인 일정 → 404; 다른 커플 → 404; GET → 405; 본문 `"x"`·`{"date": "2026-13-01"}` → 400; 성공 뒤 캘린더 페이지에 "로 옮겼어요" 와 되돌리기 버튼(옛 날짜가 오늘 이후일 때만); 로그인 필요.
