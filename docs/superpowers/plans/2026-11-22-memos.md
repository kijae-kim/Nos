## Global Constraints

- 새 앱 `memos` (INSTALLED_APPS, `config/urls.py` 에 `memos/`), 마이그레이션 `memos.0001_initial` → Neon **55**.
- 줄 검사: 목록, 줄 ≤2000, `t ∈ {text, check}`, `on` bool, `s` str ≤1000, 전체 ≤20000자. 문구 존댓말, 색 토큰, 375px·라이트/다크.
- 테스트 `cd web && ../.venv/bin/python manage.py test`. 브랜치 `feat/memos`.

## Review Focus

1. 다른 커플 메모·폴더 404, 목록·홈에 안 보임 (Task 1).
2. 옛 버전으로 저장 → 409 + 서버 줄·버전, 덮어쓰지 않음 (Task 1).
3. 잘못된 줄(t 이상, 길이 초과, JSON 아님) → 400 (Task 1).
4. 메모 있는 폴더 지우기 거절 (Task 1).
5. 붙여 넣기에 HTML·스크립트가 섞이지 않음, 제목·미리 보기 계산 (Task 1 제목 테스트, Task 2 브라우저).

### Task 1: 앱·모델·주소·화면(쓰기 칸 빼고)

- `MemoFolder`, `Memo` (설계대로), `memos/lines.py`: `clean_lines(data) -> list` (ValueError), `title_and_preview(lines) -> (str, str)`, `ensure_default_folders(couple)`.
- 뷰·주소: `memos`, `memo_folder_create/update/delete`, `memo_folder`(목록, 빈 메모 정리), `memo_new`, `memo_edit`, `memo_save`(JSON, 409), `memo_move`, `memo_delete`.
- 템플릿: `memos/index.html`(폴더), `folder.html`(목록), `folder_form.html`, `edit.html`(쓰기 칸 자리와 초기 JSON).
- 테스트 `MemoTests`: 기본 폴더 두 개, 폴더 만들기·같은 이름 거절·메모 있으면 지우기 거절, 새 메모→쓰기 화면, 저장(제목·미리 보기·버전+1), 409, 400 들, 다른 커플 404, 빈 메모 목록에서 정리, 옮기기·지우기, 로그인 필요.
- 커밋 `feat: 메모 폴더·목록·저장`

### Task 2: 쓰기 칸 (`static/js/memo-editor.js`, CSS)

- render/serialize, 체크 버튼(줄 바꾸기), 동그라미 누르기, 엔터·백스페이스 규칙, 붙여 넣기 글만, 0.8초 뒤 저장·떠날 때 keepalive 저장, 저장 표시, 409 안내·내 글 복사, 도구줄.
- 테스트: 쓰기 화면에 스크립트·초기 JSON(`json_script`). 브라우저(크롬, 375px·넓은 화면·라이트/다크)로 엔터·체크·붙여 넣기·저장·새로고침 유지 확인.
- 커밋 `feat: 메모 쓰기 칸 (체크 항목)`

### Task 3: 홈 카드·+ 메뉴

- 홈 "메모" 섹션(최근 3개, 제목·폴더, 전체 보기), + 메뉴 "메모"(`memo_new`, 마지막 폴더는 세션), 6개 버튼 자리 다시 배치.

- 커밋 `feat: 홈 메모 카드와 + 메뉴`
