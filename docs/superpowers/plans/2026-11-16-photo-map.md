# 사진 지도 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사진의 촬영 위치를 저장하고, 앨범 탭의 "지도" 칸에서 국내(카카오맵)·해외(Leaflet)로 간 곳을 핀과 색칠로 보여 준다.

**Architecture:** `Photo.latitude/longitude` 를 더하고, 위치는 브라우저(exifr, 줄이기 전)가 읽어 폼 값으로 보내며 없으면 서버가 JPEG EXIF 에서 읽는다(`couples/geo.py`). 지도는 `static/js/map.js` 가 지도 칸을 처음 열 때 데이터(`/albums/map/data/`)·라이브러리·경계 파일(`static/geo/`)을 불러와 그린다.

**Tech Stack:** Django 5.2, Pillow EXIF, exifr 7.1.3 lite, Leaflet 1.9.4 + markercluster 1.5.3 (cdnjs), topojson-client 3.1.0, Kakao Maps JS SDK (clusterer), world-atlas 2.0.2 countries-50m, southkorea-maps KOSTAT 2018 시·군·구.

**Spec:** `docs/superpowers/specs/2026-11-16-photo-map-design.md`

## Global Constraints

- 화면 문구 존댓말, 주석 한국어, 색은 토큰만. 375px·라이트/다크·배/여정 확인.
- 외부 스크립트는 정확한 버전 고정: `exifr@7.1.3/dist/lite.umd.js`, `topojson-client@3.1.0/dist/topojson-client.min.js` (jsdelivr), `leaflet/1.9.4`, `leaflet.markercluster/1.5.3` (cdnjs), 카카오 `//dapi.kakao.com/v2/maps/sdk.js?appkey=<KAKAO_JS_KEY>&autoload=false&libraries=clusterer`.
- 경계 파일은 앱에 넣는다(`web/static/geo/`), 런타임에 외부에서 받지 않는다. 합쳐 1.5MB 이하. 출처는 README 에 적는다.
- 위치는 그 커플만 본다. 지도 데이터 주소는 로그인 + 내 커플 사진만.
- 위치 읽기 실패는 올리기를 막지 않는다 (위치 없이 저장).
- 위도 −90~90, 경도 −180~180, 둘 다 있거나 둘 다 없음, (0,0) 은 없음.
- `KAKAO_JS_KEY` 없음 또는 SDK 5초 안에 못 불러옴 → 국내도 Leaflet.
- R2 LIST 금지. 마이그레이션 1개(`couples.0010_photo_location`) → Neon 확인 숫자 **48**, 배포보다 먼저.
- 테스트 `cd web && ../.venv/bin/python manage.py test`. 브랜치 `feat/photo-map`.

## Review Focus

1. 위도만 있거나 범위를 벗어난 값, (0,0) → 위치 없음으로 저장 (Task 1 테스트).
2. 다른 커플의 사진·위치 없는 사진은 지도 데이터에 절대 안 나옴 (Task 3 테스트).
3. EXIF 가 깨졌거나 HEIC·PNG 라 서버가 못 읽음 → 올리기는 성공, 위치 없음 (Task 1 테스트).
4. 카카오 SDK 를 못 불러옴(키 없음·도메인 미등록) → 국내가 Leaflet 으로 그려짐 (Task 5 브라우저 확인).
5. 사진 파일을 바꾸지 않고 사진 정보만 고침 → 위치 그대로 (Task 1 테스트).

### Task 5: 지도 그리기 (`map.js`, 경계 파일)

**Files:**
- Create: `web/static/js/map.js`, `web/static/geo/kr-municipalities-2018.topo.json` (southkorea-maps `kostat/2018/json/skorea-municipalities-2018-topo-simple.json` 그대로), `web/static/geo/world-countries-50m.topo.json` (world-atlas 2.0.2 `countries-50m.json` 그대로)
- Modify: `web/static/css/app.css` (`.map-canvas`, `.map-strip`, 색칠 색 토큰 `--map-fill`, `--map-line`, `.segment.three` 가 없으면)

**Interfaces:**
- Consumes: Task 3 의 `data-*` 속성과 JSON.
- Produces (map.js 안):
  - 지도 칸을 처음 열 때(또는 `?view=map`) 한 번만: JSON·topojson-client·경계 파일 받기, 카카오 키가 있으면 SDK(5초 제한) 아니면 Leaflet.
  - 분류: 시·군·구 다각형 안 → 국내 + 그 지역(코드). 아니면 위도 32.8~38.9·경도 124.0~132.0 안이고 어떤 나라 다각형(한국 제외)에도 안 들면 국내(색칠 없음). 그 밖 → 해외 + 나라.
  - 색칠: 간 지역만 `--map-fill` 로, 진하기는 사진 1장 0.35, 2~4장 0.5, 5~9장 0.65, 10장 이상 0.8. 테두리 `--map-line`.
  - 요약: 국내 "N곳 · 사진 M장" (N = 색칠된 시·군·구 수), 해외 "N개 나라 · 사진 M장".
  - 핀: 클러스터(카카오 `MarkerClusterer`, Leaflet `markerClusterGroup`). 핀·묶음을 누르면 그 핀(묶음)의 사진을 `.map-strip` 에 `<a href=url><img loading=lazy src=src></a>` 로, 지도는 그대로.
  - 지역 이름(시·군·구 `name`, 코드 앞 두 자리로 시·도 붙이기: 11 서울, 21 부산 … 39 제주)을 색칠 지역 위에 누르면 작은 말풍선으로.
  - `focus=lat,lng` 이면 그 자리로 이동(국내/해외 칸 자동 선택), 확대 15.
  - 처음 화면: 국내 사진이 있으면 국내, 없고 해외만 있으면 해외. 사진이 없으면 빈 상태 문구.
  - Leaflet 은 OSM 타일 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`, 출처 표기 `© OpenStreetMap`.
