# 추억 (순간 · 기록) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 취향 탭을 추억(순간·기록)으로 바꾸고, 기록에서 장소를 지도에 쌓으며 찍은 위치 기준으로 앨범 사진과 잇는다.

**Architecture:** 장소 = `Taste(category="장소")` + 위치 칸. 사진은 `Photo.place` FK 로 장소에 붙고, `couples/places.py` 가 200m 안 가장 가까운 장소로 자동 연결(직접 정한 것은 `place_manual`)을 맡는다. 장소 검색은 서버(`couples/placesearch.py`: 카카오 로컬 → 모자라면 Nominatim). 지도 JS 는 기록 화면용(`static/js/map.js` 재작성)과 장소 고르기(`static/js/place-picker.js`)로 나눈다.

**Tech Stack:** Django 5.2, urllib(기존 `linkpreview.py` 방식), Leaflet 1.9.4 + markercluster 1.5.3, Kakao Maps JS SDK, topojson-client 3.1.0 + 기존 `static/geo/` (국내/해외 판정만).

**Spec:** `docs/superpowers/specs/2026-11-19-memories-design.md`

## Global Constraints

- 문구 존댓말, 주석 한국어, 색은 토큰. 375px·라이트/다크·배/여정 확인.
- 주소 `/tastes/…` 는 그대로, 화면 이름만 "추억". 탭 표시 `?tab=moment|record` (기본 moment).
- 순간 태그 = `["영화", "음악", "영상", "책"]` (화면 순서), 꼭 하나. 장소 글 분류는 못 바꾼다.
- 자동 연결: 같은 커플·`category="장소"`·위치 있는 글 중 **200m** 안 가장 가까운 것, 같으면 작은 pk. `place_manual=True` 사진은 건드리지 않는다.
- 카카오 REST 키 = `settings.KAKAO_CLIENT_ID` (서버만). 지도 JS 키 = `KAKAO_JS_KEY`. 키를 화면·로그에 내보내지 않는다.
- Nominatim: User-Agent `NOS-couple-app/1.0` (개인 정보 없이), 서버 전체 초당 1회, 같은 검색어 결과 하루 캐시(Django cache). 외부 요청 제한 5초.
- 마이그레이션 1개 `couples.0011_places` → Neon 확인 숫자 **49**, 배포보다 먼저.
- 테스트 `cd web && ../.venv/bin/python manage.py test`. 브랜치 `feat/memories`.
